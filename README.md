
# ADIDEV

A personal portfolio website built to showcase my skills, projects, and development journey.

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Interactive functionality

## Setup Instructions

1. Clone the repository:

   ```bash
   git clone https://github.com/ADITYA-PROGRAMMER5/CodeOrbit_Personal_Portfolio_Website.git
   ```

2. Open the project folder:

   ```bash
   cd CodeOrbit_Personal_Portfolio_Website
   ```

3. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in Visual Studio Code.
